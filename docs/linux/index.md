# Linux 基础

> 从零整理 Linux 的使用与管理。它是日常开发的地基，也对齐 **NCRE 三级「Linux 应用与开发技术」** 和 **四级「Linux 应用与开发工程师」** 的考纲。

## 为什么单独开一个板块

Go2 EDU 的开发会一路用到 Linux：连服务器、看显存、起服务、翻日志。这些动作背后是同一套底子——命令怎么读、权限怎么管、进程怎么控。单独理出来，是为了让它们**成体系**，而不是每遇到一个查一个、查完就忘。

## 命令族索引

目标不是背清单，而是知道"这类事该找哪个命令"。学到哪，补到哪。

| 族 | 代表命令 | 解决什么 |
|---|---|---|
| 导航 | `pwd` `cd` `ls` | 我在哪、这儿有什么 |
| 文件操作 | `touch` `mkdir` `cp` `mv` `rm` | 增、删、改、移 |
| 查看内容 | `cat` `less` `head` `tail` `grep` | 看文件、找内容 |
| 权限 | `chmod` `chown` `sudo` | 谁能对什么做什么 |
| 进程 | `ps` `top` `kill` `jobs` | 谁在跑、怎么停 |
| 磁盘与内存 | `df` `du` `free` | 还剩多少 |
| 网络 | `curl` `ss` `ping` | 通不通、端口在不在 |
| 包管理 | `apt` | 装、升、卸软件 |
| 归档压缩 | `tar` `gzip` | 打包、解开 |
| 文本处理 | `sort` `uniq` `wc` `sed` `awk` | 加工文本流 |
