# log/：草稿区

这里的文件**不会**被构建进站点，是写给自己看的原始记录。

分工：

| 位置 | 定位 | 是否发布 |
|---|---|---|
| `log/`（就是这里） | 草稿区。当天想到什么写什么，不用管结构、不用管能不能公开 | 否 |
| `docs/log/` | 发布区。从草稿里整理出来、愿意给别人看的复盘 | 是，进站点 |

为什么分开：写的时候不用先想"这句能不能公开"，整理的时候再决定。写作和取舍是两件事，混在一起会拖慢写作。

如果哪天觉得两处太绕，合并也很简单：把这里的东西挪进 `docs/log/`，然后删掉这个目录，顺手改一下 `docs/.vitepress/config.mts` 的侧边栏。

单篇模板见 [`docs/log/template.md`](../docs/log/template.md)。
