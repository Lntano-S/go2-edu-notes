# 00_什么是 Agent

> Agent = LLM + 规划 + 记忆 + 工具 + 感知
## 四要素：
- **Planning**：决策能力
- **Memory**：连续性和上下文理解能力，其中短记忆保存在上下文中，长记忆总结成知识和经验，写入**向量数据库中**
- **Tools**：调用外部工具，如网络搜索、执行代码、读写文件、调用API等
- **Perception**：获取信息的入口，图片 语音 感知环境和用户的反馈

```Python
# Agent 核心循环
def agent_loop(user_input):
	messages = [user_input]
	
	while True:
		# 1. 思考
		response = llm.think(messages)
		
		# 2. 判断是否完成
		if response.done:
			return response.answer
			
		# 3. 执行工具
		result = execute_tool(response.tool)
		
		# 4. 记录结果，继续思考
		messages.append(result)
```

## Agent 的能力边界

| 能做什么                                                     | 不能做什么                                                       |
| -------------------------------------------------------- | ----------------------------------------------------------- |
| 1. 写代码、修bug<br>2. 搜索文件<br>3. 网页浏览、API调用<br>4. Git 工作流自动化 | 1. 理解未说清楚的需求<br>2. 处理没见过的复杂场景<br>3. 超越工具边界的操作<br>4. 替代人类做判断 |

给Agent最基础的工具即可，让其自己思考创造，防止因为Tools过多造成上下文**过长**的困扰

**Agent** 并不神秘，核心代码也就100多行，每个人都能写出一个属于自己的Agent
